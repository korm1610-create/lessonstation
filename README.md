# 📘 教科書メーカー（LESSON STATION）

学生のレベルと勉強させたい文法を入れるだけで、**会話 → 文法 → 練習問題 → 活動** の日本語教科書が作れるAIツールです。
AIが出した案から先生が選んで、直しながら作っていく流れなので、授業にそのまま使える教材になります。

👉 **使ってみる：** https://korm1610-create.github.io/lessonstation/

## できること

- 学生情報（対象・レベル・言語）を保存して、クラスごとに教科書を管理
- オリジナルキャラクターの作成（ChatGPT用のキャラシート指示文を自動作成 → 絵を貼ると正面イラストを自動で切り抜き）
- タイトル案5つ・会話文案5つから選んで、その場で修正
- 文法の説明（かたち・せつめい・例文）を自動作成、編集も可能
- 練習問題20案から5〜6問を選択、コメントで形式を指定して作り直し
- 活動（書き込みワークシート）5案から1つを選択
- 漢字に自動でふりがな、単語の意味は韓国語・英語・中国語に対応
- AIによる最終チェック（ふりがな・数え方・文法・訳の間違いなど）と、その場での修正
- 15種類のデザイン、印刷・PDF保存

## はじめ方

1. 上のリンクを開く
2. 「APIキー」に自分の Anthropic APIキーを入れて保存（[console.anthropic.com](https://console.anthropic.com) で作れます）
3. 「教科書を作る」からスタート。くわしくはアプリ内の「使い方」をご覧ください

## 注意

- AIの利用料は、入力したAPIキーの持ち主に請求されます
- APIキー・保存した教科書・キャラは、**そのブラウザの中にだけ**保存されます（サーバーには送られません）
- 共用のパソコンでは、使い終わったら「キーを削除」を押してください
- AIが作った内容は、授業の前に必ず先生の目で確認してください

## 開発者向け

- `src/App.jsx` … アプリ本体
- `src/shim.js` … ブラウザ保存（localStorage）の仕組み
- `index.html` … 公開用のファイル（GitHub Pages はこれを表示します）

`src/App.jsx` を直したら、次のコマンドで `index.html` を作り直してください。

```
npm install
npm run build
```
